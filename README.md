# Odbiory

Wydania aplikacji **Odbiory - System Zarzadzania Montazami**.

## Pobieranie

Najnowszy instalator znajdziesz w zakladce **Releases**.

Zainstalowana aplikacja sprawdza aktualizacje sama - porownuje swoja wersje
z plikiem `version.txt` w tym repozytorium i proponuje pobranie nowszej.

## Uwaga

To repozytorium zawiera wylacznie wydania i numer aktualnej wersji.
Kod zrodlowy jest prywatny.
